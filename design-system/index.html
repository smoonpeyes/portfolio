Typography

Type Scale — Plus Jakarta Sans

hero · clamp Hero Heading
display · 3.815rem Display
step9 · 3.052rem H1 / Page Title
step8 · 2.441rem H2 / Section Title
step7 · 1.953rem H3 / Subheading
step6 · 1.563rem H4 / Card Title
step5 · 1.25rem Large Body / Lead
step4 · 1rem Base body copy — the workhorse of the type scale used for all long-form content.
step3 · 0.875rem Small body — card metadata, footnotes, secondary content.
step2 · 0.75rem LABEL / BADGE / TAG
step1 · 0.64rem Fine print · legal · footnote

Monospace — JetBrains Mono

Font Weights

Regular 400 — Body copy, secondary content
Medium 500 — Emphasis, subtitles, labels
Semibold 600 — Navigation, buttons, UI labels
Bold 700 — Headings, stats, strong emphasis

Spacing

8px grid system. All values are multiples of 0.5rem (8px).

0.5 · 0.25rem · 4px — Tight icon margins
1 · 0.5rem · 8px — Icon gaps, badge padding
1.5 · 0.75rem · 12px — Compact spacing
2 · 1rem · 16px — Paragraph margins, button gaps
3 · 1.5rem · 24px — Card padding, form fields
4 · 2rem · 32px — Card grid gap, section padding
6 · 3rem · 48px — Large section gaps
8 · 4rem · 64px — Section vertical padding
12 · 6rem · 96px — Page-level section gaps
16 · 8rem · 128px — Hero padding on large screens
